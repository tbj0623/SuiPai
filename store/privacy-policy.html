随拍 · 隐私政策

生效日期：2026-10-18 ｜ 适用版本：0.7.0 及之后 ｜ 包名：com.suipai.app

结论

随拍不收集、不使用、不共享、不转让任何个人数据。 应用没有账号体系，没有服务器端，也不含任何统计、广告或崩溃回传代码。 安装后不需要联网即可使用全部功能；会出网的只有两处，且都要你亲手发起： 可选的「智能配方」总开关默认关闭，且只在你填入 API Key 并亲手按下按钮时才发（见下方「智能配方」一节）； 「互通」只在你打开那一屏、且两端都确认之后，才在局域网内的两台设备之间直传（见下方「互通」一节）。

我们接触哪些内容，存在哪里

  • 你的照片与视频帧：只读取你自己设备上的媒体库，用于在应用内展示、编辑与套用配方。
  • 编辑结果：作为普通图片文件写入本机 Pictures/SuiPai，由系统媒体库管理，你可随时在相册或文件管理器中删除。
  • 界面偏好（滤镜参数、排序、筛选条件、设备名、设置项）：写入本机的一个偏好文件，不上传。
  • 回收站：删除的照片字节移到本机 Pictures/SuiPai/回收站，账单记在本机私有目录 filesDir/trash.json；30 天后可由下次启动清理。
  • 搜索索引：为了让你能搜全库，索引把文件名、日期与 EXIF 摘要（相机型号、尺寸）写在本机私有目录 filesDir/search_index.json。它是一份可重建的缓存，删掉只会下次重扫。
  • 收藏夹（你自建的相册）与自定义配方：分别存在本机私有目录 filesDir/collections.json 与 filesDir/custom_looks.json。
  • 智能配方的 API Key：先用 Android 密钥库中不可导出的主密钥加密，再写入单独的偏好文件；明文不落盘，写入后界面不再显示。
  • 系统自动备份与换机直传：仅包含偏好文件 suipai.xml 一个；不包含任何照片，不包含存放 Key 的 suipai.ai，也不包含收藏/隐藏清单（suipai.private.xml）与自定义配方（custom_looks.json）。

权限与用途

  • 相机：仅在进入拍摄界面时申请，用于取景与拍照。
  • 读取照片（Android 13+ 为 READ_MEDIA_IMAGES，并支持系统的「仅允许访问所选照片」模式）：用于列出相册、编辑与批量整理。
  • 旧系统存储权限（READ_EXTERNAL_STORAGE ≤ Android 12L、WRITE_EXTERNAL_STORAGE ≤ Android 9）：仅为在旧版本上完成同样的读取与保存。
  • 网络（INTERNET、ACCESS_NETWORK_STATE）：只服务两件事——「互通」在同一局域网内发现附近设备并传输图片；「智能配方」在你按下按钮时，把当前照片的缩略图发往你在应用内挑定的那一家服务商（可选服务商是应用内列出的几家官方接口，不是任意地址）。应用不连接任何自有服务器。
  • 设为壁纸、震动：分别对应「设为壁纸」操作与快门触感反馈，二者由系统直接授予、不弹窗。
  • 不请求位置、通讯录、通话记录、短信、麦克风、日历权限，也不在后台执行任何数据采集。

局域网互通

「互通」在用户主动打开该界面时，通过局域网广播发现同样运行随拍的设备， 并在双方确认后将图片从一台设备直接传到另一台。传输不经过任何中间服务器； 接收方保存的文件落在其本机的 Pictures/SuiPai。

智能配方（可选，默认关闭）

这是一项可选的照片增强功能：让大模型看一眼照片，从应用自带的胶片配方库里推荐一条并说明理由。

  • 默认关闭：总开关处于关闭状态时，这个功能一次也不会出网；关掉开关后的行为与没有这个功能的版本一致（局域网的「互通」是另一件事，见上面那一节，它不受这个开关影响）。
  • 出网内容只有两样：当前这一张照片长边 256 像素的缩略 JPEG（JPEG 质量 85，平均约 11 KB），以及一段固定的提问文字。 原图、EXIF、拍摄位置、相册里的其它照片、你的文件名都不发送。
  • 发到哪里由你选：应用内列出几家服务商的官方接口（默认智谱），你在「智能配方」里挑一家；API Key 由你自己填写，随拍不代你持有任何 Key，也不代你转发到别处。 一旦发出，该照片缩略图的处理就受你所选服务商的条款约束。
  • 只在按下按钮时发生：没有后台上传、没有批量上传、没有自动重试以外的额外请求。
  • 返回的结果只是建议：它只能选择应用配方库里已经存在的条目，应用不会因为它说了一句什么就改动你的原片。
  • 随时可撤：在「智能配方」里按「清除」即抹掉本机存放的加密 Key；关闭总开关即断掉这一项的全部公网请求。

分享与第三方

应用内的「分享」调用系统选择器，由你选择的目标应用处理后续；随拍不保留副本，也不记录你分享给了谁。

儿童与数据删除

随拍不面向 12 岁以下儿童，且不收集任何用户数据，因此不存在需要代为删除的记录。 如需清除应用产生的一切设置：系统「设置 → 应用 → 随拍 → 存储 → 清除数据」，或直接卸载； 已保存的照片是相册中的普通文件，请自行删除。

只想清掉设置中心那几项（主题、字号、各功能开关）：应用内「设置 → 存储 → 清除设置」。 它只清 cfg_ 开头的偏好，不碰照片、不碰相机/一瞬/相册的既有设置， 也不碰收藏与隐藏清单。

Summary in English

SuiPai (随拍) collects no personal data. There is no account, no backend, no analytics, no advertising and no crash-reporting SDK. Photos are read from and written to the user's own device only. The INTERNET permission exists solely for the optional device-to-device transfer over the local network, which never passes through a server. Saved images live in Pictures/SuiPai. Clearing app data or uninstalling removes all preferences; saved photos are ordinary media files the user can delete at any time.
