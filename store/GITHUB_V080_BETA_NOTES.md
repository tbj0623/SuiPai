# 随拍 0.8.0 Beta 1 · 数据安全与桌面入口

这是 Android **测试预览版**，不是 Google Play / App Store 正式稳定版。Kotlin / Jetpack Compose 源码以 MIT 许可证公开。

## 这轮升级

- **跨安装备份安全门**：新备份带随机安装标识，保存在 Android 不随系统备份迁移的目录。同一安装可恢复收藏、隐藏与收藏夹照片编号；从另一设备、重装安装或旧文件恢复时，跳过这些不可移植编号，避免将无关照片误标为收藏/隐藏。设置、配方、搜索历史仍可导入。
- **结果诚实**：跨安装确实跳过关联、或任一恢复类别写入失败时，显示「部分完成」和原因，不再一律报成功。
- **原子收藏夹恢复**：账本换成 AtomicFile 写入，避免文件替换中途被中断留下半截 JSON。收藏/隐藏、搜索历史的落盘返回值现在会被检查；配方写后会重新读盘校验。
- **桌面快捷方式能直达**：「最近一张」进入最近可见照片的查看器，不主动暴露隐藏照片；「回收站」直接打开回收站。改按启动器实际容量发布，避免把「能否固定到桌面」误用作动态入口的支持判据；补充边界回归测试。
- 保留 0.7.1 的 Android 13+ 视频主动授权、Android 14+ 部分视频授权和回收站安全写入改进。

## 安装与注意

- APK 是 **Debug 签名**：Android 包名 `com.suipai.app.debug`，版本 `0.8.0-debug`（versionCode 9）；与同签名 0.7.1 测试包可原地升级。不能替代正式签名的商店包。
- **备份文件不包含照片本身**；跨设备不会自动迁移收藏/隐藏照片的关联，须在新设备手动整理。新备份格式为 **schema 2**：旧版随拍会拒绝读取，升级到 0.8 后才能导入；新版能读取 schema 1 的旧备份但跳过其照片关联。导出的 JSON 仍是明文敏感文件，请妥善保管。
- 已通过 JVM 自动化逻辑测试、Android 编译与静态检查；**尚未在真实设备验证** SAF 文档提供方、卸载重装、动态桌面入口、相机链路和双机互传。请先用非重要数据试用。
- iOS 源码仍未在 Mac / Xcode 上编译验证。缺正式 keystore 与发布者联系方式，因此尚不能作为官方应用商店版本。
- 请勿上传私人照片、定位 EXIF、API Key 或含个人信息的完整日志到公开 Issue。
